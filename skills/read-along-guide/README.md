# Read-Along Guide

Use this skill to make a companion that follows a book's argument in its own
order. Read each guide unit before the matching section of the book.
The guide breaks arguments into explicit steps for a non-expert reader.

## Typical usage

> Use read-along-guide to make a companion to this book, one chapter at a time.
> Include diagrams and linked definitions. Wait for me to say next.

## What to expect

- Agreement on the edition, coverage and pace before writing.
- Chapter guides with argument steps and short quotations checked against the source.
- Reconstructed author figures and explanatory diagrams where needed.
- A separate definitions file linked from the guide.
- Guide files and images delivered as a ZIP; a combined PDF when requested.

The default pace is one chapter per turn, followed by your go-ahead.
Outside context is labelled; evaluation of the author is included only if requested.
