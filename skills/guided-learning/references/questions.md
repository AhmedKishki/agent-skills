# Asking questions

These rules apply to questions in the diagnosis and in checks; exercises follow [exercises.md](exercises.md). Base every question on sourced material, so that its correct answer has a reference.

## Multiple-choice questions

Pose them in the AskUserQuestion dialog where the host has it. One call holds up to 4 questions, each with 2–4 options.

- Write each question so that it stands on its own, because the dialog can hide the text above it. Use `Q1`, `Q2` and so on as headers.
- Vary the position of the correct option and give it nothing that marks it. Never add "(Recommended)", and write every option's description in the same style and length, so that none stands out.
- Put the answer text in the label. When an answer is too long for a label, put a short form in the label and the full text in the description.
- Use single choice unless the question says "select all that apply".
- The dialog adds an "Other" field. Tell the student once that they can type "I don't know" or their own answer there.

Without the dialog, write the options as lettered text (A–D) and ask the student to reply like `1B, 2D`.

## Free-thought questions

These ask the student to explain, predict, compare or work something out in their own words, so the answer shows how they reason and not only what they pick. Once the dialog returns, write them as plain text in the same turn, numbered after the multiple-choice questions, and end your turn.

Give feedback on all the answers together once the free-thought answers arrive, so the dialog answers aren't graded before the student has finished.
