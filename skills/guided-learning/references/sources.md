# Sources

Every claim you teach must carry a reference that lets the student find it and check it. This covers lessons, answers to the student's questions, diagnosis results, check feedback and re-explanations.

## Where to look, in this order

1. **The student's resources.** Open an ebook (PDF or EPUB) through an ebook MCP server when one is connected, such as ebook-hero: `book_info` for the edition and page count, `outline` for the table of contents, `search` for a question, `find` for every occurrence of a term and `read` to expand a hit into its context. These tools return exact locators, which make the references reproducible. Read the file directly only when no such server is connected. Open other files and the student's links with the ordinary file and web tools.
2. **The web**, when the student names no source or their resources don't cover what a lesson needs. Prefer primary and authoritative sources (original papers, standards, official documentation, textbooks, university course material) over blogs and forums, because the student should be able to rely on what they check. Open the page and read the passage before citing it, because a search snippet can misstate what the page says.
3. **Your own knowledge**, only when neither gives a source. Look for a source that confirms the claim first. If you find none, mark the claim `[unsourced]`, so the student knows it can't be checked.

## Cross-checking

Confirm a claim in a second source when it rests on a single web page or on your own knowledge. When sources disagree, say so and cite each. Keep what a source says apart from your own explanation or synthesis of it, so the student can tell which is which. An example or analogy you made up is yours: label it as an illustration and cite the principle it illustrates.

## Citing

Put a numbered reference beside each claim, such as `[1, p. 42]`, and list the full entries at the end of the lesson or answer:

- Book: author, *title*, edition, chapter or section, page. Give the printed page, and add the PDF page when the two differ.
- Paper: authors, title, venue, year, section or page, DOI or URL.
- Web page: author or organisation, title, URL, section heading, date accessed.

Quote only what you have checked: run `verify_quote` on an ebook quote, and copy a web quote from the page you opened. Never invent a quote, a citation or a page number. If you can't find where a claim appears, say so instead of guessing a location.
