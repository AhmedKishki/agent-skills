# Humaniser

Install it in Claude Code 2.1.275 or later with `/plugin install humaniser --marketplace AhmedKishki/agent-skills`; for other agents, see the [collection README](../../README.md#install).

Use this skill to review a text against the AI writing syndromes in [references/syndromes.md](references/syndromes.md). It identifies and fixes each syndrome and reports to you.

> Use humaniser to review this lesson against the syndromes.
