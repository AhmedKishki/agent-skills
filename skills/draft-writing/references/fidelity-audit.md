# Fidelity audit

Check the requested article scope against thesis, arc, selected predraft, original user wording and sources.

1. State the checked scope and available originals.
2. Follow each compact provenance line to its exact human bases. Check whether the prose can be feasibly reconstructed through permitted operations; report an unsupported span precisely.
3. Check each argument's prose coverage and original fragments, source meaning and qualifications, and citation scope. Verify that arguments establish paragraph claims and paragraphs establish section claims or answer their governing questions.
4. Check that current user edits, numbering and selection authority correspond to the intended content.
5. Present each issue with its location, consequence and proposed owner correction. Ask for consent before a substantive fix.

## Output

Respond with:

- **Checked:** scope and access limits.
- **Result:** checks passed for this scope, or issues remain.
- **Findings:** location, problem and consequence, proposed correction and owner; include when issues exist.

Create `# Fidelity audit` with these fields only when a file is requested. Treat the saved trail as a basis for verification, without asserting an exact historical sequence of operations. Present a full construction record for any proposed synthesis revision. Apply accepted corrections in their owners, recheck affected work, and return changed paragraphs to the user's approval loop.
