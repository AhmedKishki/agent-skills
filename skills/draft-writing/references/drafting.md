# Drafting

## Purpose

Compose reader-facing article prose in `{project}-draft.md` from an approved article-arc version.

## Procedure

1. Work in approved arc order, one complete section or other user-approved unit at a time.
2. Present its arc requirements and assigned argument drafts before composing.
3. Ask the user for missing wording before offering AI wording.
4. Apply AI-authored wording only after approval of the exact bounded span.
5. Save approved prose in the live draft and record current state in progress.
6. If a prose problem changes an argument, evidence or structure, return to that owner before continuing.
7. Assemble approved units without adding prose.
8. After approval of the complete uncited article, save it unchanged as `{project}-draft-vN.md` with `Status: Finalised`.

## Draft format

The article appears first and contains only reader-facing prose. If a short working note is necessary, put it after a horizontal rule and remove it from the finalised snapshot.

## Completion

Every unit is approved, the complete prose conforms to one approved arc version, no prose was added during assembly and the user approves the final uncited article.
