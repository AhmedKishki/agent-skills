# Input routing

## Purpose

Classify each independent part of new input and send it to one authoritative file.

## Routes

### Thesis or interpretation

Route an article-wide claim, purpose, question or metatheoretical commitment to the thesis.

### Draft direction

Route audience, length, voice, publication, emphasis and formal requirements to draft direction.

### Exact reusable user wording

Preserve user-authored definitions, claims, analogies, examples and candidate prose in user material. Link its stable ID from the file where it is used.

### Source material

Route a supplied publication, document or quotation to source mapping. Source wording remains source-authored even when the user supplies it.

### Argument

Route one claim, qualification or dependency to argument formation.

### Synthesis selection

Route exact user-material and source-excerpt selections for one argument to synthesis material.

### Article structure

Route order, stages, sections, passages, paragraph purposes, transitions, recurrence, inclusion and omission to the article arc.

### Draft prose

Route reader-facing composition and prose edits to the draft.

### Procedure

Execute approvals, rejections, requests and navigation commands. Do not preserve them as article material.

## Ambiguity

When one unit could belong to incompatible owners, ask one focused question before saving that unit. A contribution may be preserved once as exact user material and referenced by its substantive owner; do not duplicate its exact text across files.

## Completion

Every input unit has one substantive owner and exact wording has one stable home.
