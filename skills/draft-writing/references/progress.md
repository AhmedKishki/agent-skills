# Progress

## Purpose

Record only the current workflow position, blocking question, next actions and counters in `{project}-progress.md`.

## Procedure

Update after every proposal, approval, rejection, gap, save, invalidation, version or focus change. Do not turn this file into an archive or full file inventory.

## Format

```markdown
# Progress

## Current work

**Stage:** Argument synthesis

**Current item:** ARG-014

**Status:** Candidate awaiting decision

**Revision:** ARG-014-r1

## Current question

Do you approve ARG-014-r1, or what should change?

## Next actions

### After approval

Save the argument draft and resume the affected article-arc question.

### After comments

Prepare ARG-014-r2.

## Counters

- Next source code: B
- Next user-material ID: U-023
- Next argument ID: ARG-023

## Sources in progress

### Source A

**Original:** sources/example.pdf

**Coverage:** Pages 1–12 checked.

**Next excerpt:** A5
```

## Resumption

Verify the named files and state. Re-present an exact pending proposal before interpreting a later approval.

## Completion

The current item, exact question, next actions and counters are sufficient to resume.
