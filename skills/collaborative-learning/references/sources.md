# Sources and References

## Select and inspect

- Use sources specified by the user as the basis of the learning plan.
- Ask before replacing or supplementing a specified source set.
- When no sources are specified, find appropriate sources for the requested subject.
- Prefer primary texts, original research, or authoritative documentation as appropriate.
- Inspect the actual source content before mapping or explaining its arguments.
- Identify the edition or version where it affects wording, pagination, or content.
- If necessary content is unavailable, disclose the gap and ask for the material
  or agreement to use an accessible alternative; do not invent its arguments.

## Ground each explanation

- Base every substantive explanation on inspected source passages.
- Preserve distinctions, qualifications, and steps in the source's reasoning.
- Distinguish a source's claim from the agent's interpretation or synthesis.
- Make interpretive reasoning traceable to the passages supporting it.
- Identify disagreements between sources when relevant to the explanation.
- Do not present a synthesis as though every source makes the same argument.
- Label an illustrative example as illustrative and ground the point it explains.
- Do not invent events, quotations, citations, or source locations.

## Cite clearly

- Place references beside the claims or arguments they support.
- Honour the user's reference format when specified.
- Otherwise use numbered references with complete entries in each session file.
- Include author or issuing body, title, edition/version where relevant, and location.
- For books, give chapter, section, and page where available.
- For unpaginated material, give the heading and a stable passage locator.
- Distinguish printed page numbers from PDF viewer pages when they differ.
- For web sources, include the URL and relevant heading or section.
- Give full reference details again in each session; never use an earlier session
  as the location of the evidence or bibliography.
- Preserve portable references in Markdown files as well as any chat citations.
- Quote accurately and only as much as needed and permitted.
