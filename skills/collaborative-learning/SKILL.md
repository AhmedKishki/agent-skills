# Collaborative Learning

## Workflow

1. Read `references/planning.md` and `references/sources.md` before proposing a plan.
2. Clarify missing scope or source requirements with the user; do not assume them.
3. Inspect specified sources, or find appropriate sources when none are specified.
4. Present the session count first, then the topics, subtopics, sources, and sequence.
5. Invite confirmation or adaptation. Wait for confirmation before teaching.
6. Read `references/teaching.md` and `references/records.md` before starting a session.
7. Teach the approved topics in order, with concise, direct, plain explanations.
8. Save each topic's explanation and interactions in `project/session-n.md`.
9. Offer optional exercise questions at the end of a session.
10. Continue through the confirmed plan at the user's pace.

## Resource map

| File | Read when | Apply to |

## Package maintenance

Keep every file in this skill package at 100 lines or fewer.
Split additional instructions into directly linked reference files when needed.
Apply this limit to skill files, not to the learning records generated by the skill.
