# Collaborative Learning

Learn a book, concept, material, or subject through a plan you confirm or adapt.

Start with a request such as:

> Use collaborative-learning to help me study Chapter 3 of this book, argument by argument.

The agent inspects your specified sources, or finds appropriate sources when none
are specified. It presents the number of sessions first, followed by the topics,
related subtopics, and sources. Teaching begins after you confirm the plan.

Each topic forms one session. Explanations use plain language and clear references.
Questions and clarifications stay with their topic. Every explanation develops
the full argument, including any necessary repetition.

The learning project contains:

- `plan.md`: the confirmed plan and progress.
- `session-n.md`: each topic's explanations, discussion, references, and optional exercises.

See [SKILL.md](SKILL.md) for the agent workflow.
