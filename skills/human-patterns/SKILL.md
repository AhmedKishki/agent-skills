# Human patterns

Review the input against the syndromes in [references/syndromes.md](references/syndromes.md). Read that file before every review.

1. Identify each passage of the input that shows a syndrome.
2. Fix it.
3. Report to the user: each passage, its syndrome and its fix.

Against the AI patterns, following the KISS principle is a good rule of thumb. Occam's razor: the minimal model description is the preferred one. Added complexity must be justified.
