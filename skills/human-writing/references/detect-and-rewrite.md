# Check and rewrite

When the user supplies a text, apply the same method to sentences you did not write. Take the mode from the request. If the request does not say whether to check or to rewrite, ask.

## Check

Use this mode when the user asks you to find superfluous argument or wording, or to check a text with human-writing.

1. Divide the text into its parts and state the purpose each part implies. A part with no purpose you can state is the first finding for that part.
2. Justify every sentence in the format from SKILL.md.
3. Give every repair or cut verdict a fix: replacement wording, the relation to state, a move, a merge or a cut.
4. Return the justification. Write no rewrite.

## Rewrite

Use this mode when the user asks you to rewrite a text with human-writing.

1. Check the text as above, in your working.
2. Rewrite by the verdicts. Fix structure first by reordering, merging and cutting, then fix wording.
3. Keep the text's claims, evidence, qualifications, citations, technical terms, voice and register. Add no fact, motive, source or connection that the text does not support. If a passage has two plausible meanings, ask before choosing one.
4. Justify the rewritten prose.
5. Return the rewritten prose, then its justification, then the removed sentences, each with the rule it failed.
