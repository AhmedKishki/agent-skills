---
name: "agent-md-refactor"
description: Refactor agent-generated markdown of any kind — instruction files, skills, plans, progress logs, reference material, drafts — so each file does its job sufficiently, holding everything its job requires and nothing outside it. Holds operative decisions only, keeps one authoritative owner per rule and per type of information, confines information about files to one meta view, and audits that nothing load-bearing was lost. Use when a markdown file an agent reads or maintains has grown long, mixes unrelated concerns, duplicates rules, contradicts itself, repeats project-wide rules, carries superseded state, lacks what its job requires, or describes other files.
---
