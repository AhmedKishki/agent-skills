# Stage 3: global and local article arc

Build from active thesis-and-vision, source maps, user-synthesis, and predraft. Begin with approved main questions. Add one only when the user agrees it is needed to establish, test, qualify, or conclude the thesis; sources may reveal the need but cannot expand scope.

The **global arc** gives each section its questions, goal/motivation, thesis contribution, include/exclude boundary, entry, exit, adjacent handoffs, and source contributions. The **local arcs** give each paragraph its claim, role, section contribution, boundary, entry/exit/handoff, source contributions, predraft passage, draft action, and repetition home.

Every paragraph makes one distinct section contribution; every section serves a question and the thesis. Remove filler, loops, excess scope, and repeated claims outside their sole home.

Structural fields require exact user wording or an exact selected Mixed/AI process proposal. Sources establish contributions, not structure. Leave unsupported fields **Undecided** and ask. Each claimed source contribution needs an active item and states its Article role and function—claim, mechanism, evidence, example, qualification, limit, or contest; missing support triggers rescan. Cross-source relations require source/user support or a labelled post-rescan AI gap suggestion.

Apply metatheory fit silently; Framework-only material is not an article contribution. Use one full-name source key; global rows aggregate contributions and local rows name items. Copy no source passages, synthesis traces, or separate matrices.

Treat the article title and every reader-facing heading as separate predraft passages with named arc placements and **Draft action**. Arc-only structural labels are not article wording.

In combined cells use these labels exactly: **Raised / Resolved**; **Goal / Motivation / Thesis contribution**; **Include / Exclude**; globally **Previous handoff / Entry / Exit / Next handoff**; locally **Role / Section contribution**, **Builds from / Exit-handoff / Prepares next**, and **Predraft / Draft action / Repetition home**. A row is **Undecided** until every required cell is set and **Resolved** only when every cell is set and each Mixed/AI field has exact-field assent.

The Human declaration covers every Human cell and substantive label. One row-level basis covers shared Human fields; stamp only Mixed/AI exceptions. Before resolving an argument, complete its rescan and bind roles to active maps. Use one row per paragraph. Keep undecided cells, not questions. Set **Include unchanged** only after the exact predraft passage exists and the user selects it for that row; earlier arc approval cannot select later wording.
