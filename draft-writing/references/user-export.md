# Requested user export

Create `{project}-user-export-YYYY-MM-DD-HHMMSS.md` only on an explicit **user export** request. It is a request-only Markdown current-state copy, never a canonical record, approval, drafting input, source export, or hand-off. With no active substantive content, report that and create nothing. Reuse only while the exact included canonical files, source-map versions used by its key, stage/state, **Now/Next**, and open question/suggestion set are unchanged.

## Assembly

Copy substantive content exactly; add no article wording, relation, decision, or synthesis. Allow only meaning-preserving process rendering. Remove top-level processing headers, file-level **Status**/**Depends on**, duplicate source keys, and empty sections. Preserve substantive states, Draft actions, citations, metrics, and the widest provenance declaration plus local exceptions. In process references only, replace versioned filenames/timestamps with readable section labels or source/item codes; change no substantive wording or source identity.

Keep thesis-and-vision and the reader-facing draft intact. Replace each full-span user-synthesis duplicate of thesis/draft wording with an internal reference. Do the same for each predraft duplicate of thesis, retained user-synthesis, or draft wording. Each reference must point directly to retained full wording and keep its distinct basis/use/provenance. Never collapse non-identical wording.

After `# User export` and **Process prose: AI**, use these headings in order; omit absent optional sections:

1. **Source key:** code → full human-readable source name, in assigned code sequence; with no maps, **No coded sources recorded.**
2. **Current work:** plain stage/state, **Now**, and **Next**.
3. **Thesis and vision:** exact substantive content/provenance.
4. **User synthesis:** exact substantive content/provenance.
5. **Article arc:** exact substantive content/provenance, without its source key.
6. **Predraft:** exact substantive content/provenance or direct duplicate references.
7. **Current draft:** exact article, provenance appendix, and metrics.
8. **Current draft changelog:** exact substantive rows/provenance.
9. **Current open collaborative questions:** every pending substantive question with its existing suggestion, consequence, origin, Human percentage, and full-name/user-wording bases.

Copy the reader-ready meaning of tracker **Now/Next** without backend references; if either is not reader-ready, ask and update it first. This is not Q&A history: resolved answers appear once in their copied canonical section. Omit acknowledgements, approvals, alternatives, superseded direction, and resolved discussion. If a pending question/suggestion is unavailable exactly, ask it anew before export; never reconstruct it. Route governing answers before export; ask if their home is unclear.

Exclude source maps/originals, index, source export, hand-off, tracker file lists, migration records, conversions, inactive files, and history. Retain quotations already in predraft/draft; add no standalone source-map or index material.

## Save and checks

Save and track per [file-output-standard.md](file-output-standard.md); saving changes only the active-file row, never semantic stage/state/**Now/Next**. When a reuse basis changes, retire the stale export through shared cleanup and regenerate only on a new request.

Before delivery, verify all copied content/provenance against its canonical version, allowing only headings, internal references, process-reference normalisation, and whitespace changes. Confirm every code resolves in the opening key, current work matches the tracker, every internal reference resolves, no resolved answer or non-identical passage was deduplicated, and no inactive/superseded material remains.
