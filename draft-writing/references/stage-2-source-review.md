# Stage 2: collaborative source review

Work source by source from approved thesis-and-vision. Read the whole accessible text or record the exact access limit; assign the tracker's next [source-map](source-maps.md) code.

For each source, follow [source-maps.md](source-maps.md) to:

1. map every main argument/move, used or unused;
2. retain each directly supportive, qualifying, or contesting claim, argument, concept, conclusion, or requested example as a minimal one-topic exact excerpt;
3. resolve separate Article and Framework roles, source/item qualifications, coverage, and provenance;
4. save each item once and add it to the [index](index.md);
5. show the user the full source name, readable excerpt/role, and uncertainty, then ask plainly.

Review sources independently and keep meaningful repetition. Only Article-role items feed synthesis; Framework-only items silently test fit. Apply operative metatheory without force-fitting, treating it as article evidence, or importing its vocabulary. Ask when selection, role, relation, or fit is unclear.

Create no registry, summary, or evidence map. A source that qualifies, contests, or may strengthen the thesis triggers a plain-language question and any accepted revision returns to Stage 1. Establish cross-source relations only from source/user support, complete-Human reductive synthesis, or a labelled post-rescan AI gap suggestion.

Stage 2 ends when every active source map and role is resolved. Framework-changing material returns to Stage 1. Before predrafting each argument, use source paths and the index to rescan every plausibly relevant original; also rescan after a missing step, requested example, vision change, or user request. Append only newly relevant excerpts, update the index, and reopen only affected work. Process one argument at a time.
