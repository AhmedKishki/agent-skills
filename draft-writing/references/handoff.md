# Requested hand-off

Create {project}-handoff-YYYY-MM-DD-HHMMSS.md only when the user explicitly requests a hand-off document. Never infer the request from a pause, completed stage, migration, or change of conversation.

Its sole purpose is seamless continuation by another AI agent. It is a current resume snapshot, not a canonical content source, approval, migration report, or replacement for the activity tracker. Reference article content and decisions instead of copying them. Stamp any substantive summary under [authorship-and-provenance.md](authorship-and-provenance.md); the hand-off is never an article or synthesis input.
