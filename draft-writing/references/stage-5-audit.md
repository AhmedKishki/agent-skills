# Stage 5: fidelity audit

Audit the complete draft against active thesis-and-vision, source maps, referenced user-synthesis, both arc scales, predraft, and index.

Verify:

- thesis, scope, exclusions, vision, and only user-selected thesis-required questions;
- silent operative-metatheory fit, with no imported framework exposition or unsupported framework wording;
- every passage's Article/Framework roles and eligibility, including MT-only exclusion;
- meaning-preserving support for each source-derived claim/reformulation/synthesis; exact quotation, locator, qualification, attribution, and narrow citation scope;
- source paths stayed navigation-only; relevant originals were rescanned; new support entered numbered, indexed items; every index code resolves;
- every active excerpt change triggered and completed its index refresh before later work;
- every section has a question, goal, thesis contribution, boundary, and handoffs; every paragraph has one claim, section contribution, role, source contribution, and linear build-up; neither scale contains filler, loops, excess, abrupt gaps, or premature conclusions;
- every assistant white box synthesis—and legacy assistant synthesis marked white-box compatible—used only original Human inputs and closed-list operations, remained terminal Mixed at 100% Human wording, passed its target/metatheory tests, and retained its complete final white box record;
- no assistant synthesis underlying the draft crossed an unreported gap or used a black-box transformation; every stopped gap supplied no passage and remained unresolved unless later restarted from eligible Human bases;
- every AI gap passage retains named search coverage, unsupported/non-synthesis status, source limits, predraft selection, and exact **Include unchanged** placement;
- inherited/local provenance, Human percentages, methods, bases, separate uses, and draft totals cover every reader-facing word;
- every draft span resolves to one active predraft passage and one exact arc action; no unauthorised wording, relation, overclaim, or repetition remains;
- every semantic omission and physical file retirement stayed within a removal impact shown to and authorised by the user.

User selection never cures a fidelity failure. Apply Human-preserving corrections to eligible non-white-box passages in predraft, then regenerate affected draft text and metrics. For a white-box-derived passage, restart from original Human bases, replace its selected passage and final record only after new selection/removal authority, then regenerate affected draft text and metrics. For any missing word, relation, source support, role, or decision, ask in plain language and return to the earliest affected stage; obtain separate predraft and placement decisions when required.

Show only unresolved decisions, create no audit file, and retain only work passing the [unaffected-work test](file-output-standard.md). Finish only when the user declares the draft complete.
